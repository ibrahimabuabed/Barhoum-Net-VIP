# 🚀 Barhoum Net VIP - نظام إدارة شبكات المايكروتك

نظام متكامل واحترافي لإدارة شبكات الإنترنت المحلية (MikroTik). تم تصميم النظام لتقديم تجربة مستخدم استثنائية (VIP) للعملاء، مع أتمتة كاملة للعمليات الإدارية والمالية لموزعي الإنترنت من خلال دمج تقنيات الويب مع روبوتات تيليجرام (Telegram Bots). 

تم بناء هذا النظام ليكون حلاً تقنياً يستجيب لتحديات الواقع، ويسهل حياة الناس ويضمن اتصالهم بالعالم الخارجي.

## 🔥 الميزات الرئيسية

- **🛡️ أمان وسهولة الوصول (مصمم لواقع غزة):** يتيح النظام للمستخدمين شراء كروت الإنترنت وتجديد الاشتراكات من داخل المنزل بكل أمان وسهولة، مما يجنبهم مخاطر وصعوبات الخروج للبحث عن نقاط البيع المادية في ظل الظروف والتحديات الحالية.
- **💳 محفظة رقمية ذكية:** نظام مالي داخلي يتيح للعملاء شحن أرصدتهم بسهولة باستخدام نظام كروت الشحن السريعة (Scratch Cards) المكونة من 14 رقماً.
- **🤖 إدارة لحظية عبر تيليجرام:** بوت تيليجرام مدمج (Webhook/Polling) يرسل إشعارات الطلبات المباشرة لمدير الشبكة، ويتيح له (الموافقة / الرفض) بضغطة زر واحدة من داخل المحادثة الخاصة.
- **📷 الدخول السحري (QR Auto-Login):** توليد رموز استجابة سريعة (QR Code) مشفرة ببيانات الكرت، تتيح للعميل تسجيل الدخول لشبكة المايكروتك فوراً بمجرد مسح الكود دون الحاجة لكتابة اسم المستخدم وكلمة المرور.
- **💎 تصميم عصري وأنيق (Glassmorphism):** واجهات مستخدم متطورة مبنية بنمط "الزجاج الشفاف" مع دعم كامل للوضع الليلي (Dark Mode) لتجربة بصرية مريحة وحديثة.
- **📊 لوحات تحكم ذكية متعددة الأدوار:**
  - **العملاء:** متابعة الرصيد، الطلبات السابقة، ونقاط الولاء.
  - **الإدارة:** إدارة بطاقات الشحن، طلبات الرصيد، ومتابعة حركة المبيعات.
- **🏆 نظام تصنيف العملاء:** ترقية تلقائية لمستوى العميل بناءً على حجم استهلاكه (مبتدئ 🥉، فضي 🥈، ذهبي 🥇، VIP 👑).

## 🛠 التقنيات المستخدمة (Tech Stack)

- **لغة البرمجة (Backend):** Python 3
- **إطار العمل (Framework):** Flask
- **قاعدة البيانات:** SQLite (جاهزة للترقية إلى PostgreSQL)
- **واجهات المستخدم (Frontend):** HTML5, CSS3, JavaScript
- **الربط البرمجي (API Integration):** Telegram Bot API (عبر مكتبة pyTelegramBotAPI)
- **توليد الأكواد:** qrcodejs
